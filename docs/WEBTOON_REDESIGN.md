# CLOCK OUT! 웹툰형 리디자인 — 2026-10-14

## 디자인 목표

기존 GTA풍 네온 포스터 UI 대신 읽기 중심의 **독창적인 한국형 디지털 웹툰 문법**을 적용했습니다. 특정 서비스의 상표, 공식 아이콘, CSS, 로고, 썸네일은 사용하지 않습니다.

### 화면 구성

1. **작품 홈**: 큰 세로 표지, #오피스판타지 태그, 1화 시작/이어보기, 회차 목록, 등장인물 소개.
2. **등장인물**: 4명의 직장인 프로필 카드, 반응형 캐릭터 상세/고유 스킬/캐릭터 선택.
3. **회차 목록**: EP.01 오픈 오피스, EP.02 무한 회의실, EP.03 심야 서버실. 자유 회차 선택.
4. **컷툰 리더**: 회차 진입 시 컷을 세로 스크롤로 읽으며, 다음 컷·건너뛰기로 진행. 3컷 후 2D 전투 진입.
5. **스토리 선택**: 전투 중 선택지는 만화 말풍선과 독립적인 선택 카드로 표시.
6. **전투 HUD**: 진한 색 배경 위에 시간·체력·스킬 등의 정보를 유지하면서 색 대비와 배치를 단순화.

## 기존 시스템과 호환성

- 기존 저장 키 `clockout.office.v1` 및 `settings.tutorialSeen` 그대로 유지.
- 캐릭터 4명, 스테이지 3개, 스킬/돌진, 강화/진화, 분기/결말, 모바일 터치 패드 유지.
- 외부 JS/CSS 다운로드가 필요 없는 단독 `aftergrow/index.html`을 계속 배포.
- 웹툰 이미지와 일러스트는 프로젝트 자체 SVG 자산을 활용.

## QA 범위

- 빠른 Chromium 회귀 테스트: **35/35 로컬 통과**.
- 새 시나리오: 작품 표지·회차 3개·캐릭터 카드 4개 및 회차 직접 진입; 세로 컷 누적과 목록 복귀.
- 데스크톱 1440×900, 모바일 390×844 / 320×640, 가로 844×390 화면에서 스크롤·가로 넘침 확인.
- 전체 장시간 자동 전투 시뮬레이션은 로컬 제한 시간 안에 완료하지 못해 별도 검증 대상으로 남아 있음.
- 실제 iPhone Safari/Android Chrome 실기기 검증은 별도 작업 필요.

## 변경할 소스

- `aftergrow/src/js/app.js`: 작품 홈/회차/등장인물/컷툰/스토리
- `aftergrow/src/styles.css`: 밝은 웹툰 디자인 시스템과 전투 HUD
- `aftergrow/src/index.html`: 내비게이션 문구 및 시맨틱 표시
- `aftergrow/tests/browser_checks.py`: 웹툰형 화면 진입 및 컷 누적 검증

**배포:** `python aftergrow/build.py`로 단독 실행 HTML 재생성 후 커밋해야 합니다. PR에서는 GitHub Actions가 CSS/JS 빌드 일치와 브라우저 기능을 검증합니다.
