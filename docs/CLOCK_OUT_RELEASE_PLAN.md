# CLOCK OUT! — 정식 공개를 위한 제품화·출시 기획서

> 작성일: 2026-10-14 | 상태: v1.0 계획 초안 | 대상 저장소: https://github.com/beerAndNacho/game_enjoy

## 1. 프로젝트 개요

**제품명:** CLOCK OUT! — 퇴근 전쟁  
**장르:** 싱글플레이 2D 오피스 서바이벌 액션 / 자동 공격 로그라이트  
**핵심 문장:** “퇴근 3분 전, 회사가 미쳐버렸다. 직장인이 되어 야근 알고리즘을 물리치고 퇴근하라.”  
**대상:** 10~30분 안에 가볍게 즐기는 한국어 웹게임 플레이어, PC/모바일 브라우저 사용자  
**최우선 목표:** 설치와 로그인 없이 공개 HTTPS 주소에서 실행하고, 오류 없이 3개 스테이지를 끝까지 플레이할 수 있는 버전 1.0 배포

**범위 가정:** 1인 개발 중심, 한국어 우선, 무료 공개 베타, 서버·회원가입·결제·멀티플레이 제외. 강렬한 도시 액션 포스터 분위기는 참고하되 GTA 원작 IP는 사용하지 않는다.

## 3. 출시 기준: '사용 가능한 수준'의 정의

다음 7개가 모두 충족되어야 **v1.0 공개 가능(Go)**으로 판정한다.

1. **접근성:** 공개 HTTPS URL에서 로그인·설치 없이 로딩된다. PC와 모바일에서 시작·재시작·종료 가능하다.
2. **완주 가능:** 선택한 직장인으로 3개 스테이지를 순서대로 플레이할 수 있다. 보스 처치, 사망, 클리어, 보상이 정상 반영된다.
3. **조작/안내:** 신규 사용자 10명 중 8명 이상이 별도 설명 없이 1분 내 이동·돌진·특수 스킬을 사용한다(테스트 목표).
4. **저장:** 새로고침·브라우저 재시작 후 선택 캐릭터, 업무 포인트, 강화, 클리어 기록이 유지된다. 저장 불가 환경은 안내하되 게임은 진행 가능하다.
5. **성능:** 1440px 데스크톱 목표 평균 60FPS, 기준 중급 모바일 목표 평균 30FPS 이상. 3분 이상 연속 전투에서 심각한 끊김·입력 지연·메모리 증가가 없어야 한다.
6. **안정성:** 정식 출시 차단 버그(P0) 0건, 게임 진행을 막는 P1 버그 0건, 핵심 여정 자동 테스트 100% 통과. 실제 기기에서 오류 재현 테스트 통과.
7. **운영:** 배포·롤백 방법, 버전 번호, 이슈 접수 경로, QA 체크리스트와 변경 내역이 저장소에 있다.

위 수치는 **검증 목표**이지 현재 달성한 성능이나 이용자 지표가 아니다.

## 4. 우선순위별 개발 범위

### P0 — 공개 전 필수

**A. 배포·품질 파이프라인**
- GitHub Pages 또는 적합한 정적 호스팅으로 `/game_enjoy/aftergrow/` 경로에서 공개 접근 가능하도록 설정.
- Pull Request마다 소스 빌드(`python aftergrow/build.py`), 산출물 일치 여부, 브라우저 회귀 테스트를 실행하는 GitHub Actions 구축.
- 배포 실패 시 직전 안정 버전으로 복구 가능한 릴리스 태그·롤백 절차 확보.
- 루트 README 명칭·실행 링크·배포 안내 최신화.

**B. 첫 플레이 경험**
- 진입 → 직장인 선택 → 이동/공격 → 커피 머신 → 보스 → 결과 화면의 흐름을 30~60초 내 이해하도록 안내.
- 모바일에서 가상 조이스틱과 스킬·돌진 버튼 위치를 재배치/검증. 터치 영역은 최소 44×44 CSS px 목표.
- 실수로 브라우저를 벗어났거나 탭이 숨겨진 경우 자동 일시정지. 복귀 시 중복 입력과 오디오 상태 복원 검증.
- 사망 원인, 다음 개선점, 다시 도전, 다른 직장인 선택 동선을 명확하게 표시.

**C. 게임 밸런스와 재미**
- 캐릭터 4명 × 스테이지 3개, 총 12개 조합으로 최소 3회씩 완주 시도하고 난이도 기록.
- 첫 스테이지에선 학습, 두 번째는 회피·선택, 세 번째는 스킬·빌드 활용을 요구하도록 난이도 곡선 조정.
- 보스 위험 공격 0.5~1초 전 명확한 시각 예고, 피격 피드백과 공격 범위 경고 제공.
- 특정 캐릭터나 무기 조합의 압도적 우위·사실상 클리어 불가능한 조합 제거.

**D. 실제 브라우저 안정성·저장**
- Android Chrome 및 iPhone Safari 실기기, 데스크톱 Chrome/Edge/Firefox/Safari(가능한 범위)에서 회귀 테스트.
- 실제 배포 URL에서 새로고침, 닫았다 열기, 시크릿 모드·저장 차단, 손상 데이터, 저장 스키마 업데이트 시험.
- 브라우저 크기 변화, 화면 회전, 통화/알림 전환, 백그라운드 복귀에서 시간·HP·입력 이상 유무 확인.
- 3분 생존 동안 적 100개 이상·이펙트 다량 발생 시 프레임과 메모리 측정 및 최적화.

**E. 기본 운영·안전**
- 고객에게 보여줄 오류 안내와 재시도 동작 제공. 플레이 진행 불가 버그는 이슈 템플릿으로 제보받기.
- 저장 데이터가 기기/브라우저별 로컬 데이터임을 고지하고 초기화 방법을 안내.
- 사용 폰트·이미지·사운드·게임명 권리 검토. 특정 기존 게임의 로고·공식 그래픽·캐릭터를 복제하지 않기.
- 개인정보 수집 없는 초기 버전을 기본값으로 하며, 추후 분석 도구를 넣을 경우 수집 내용·안내·정책 검토.

### P1 — 베타 결과를 보고 추가

- 오피스 풍 배경음악 루프와 보스전 음악, 효과음 볼륨 슬라이더.
- 스테이지별 특수 기믹 1개씩 강화(회의실 일정 구역, 서버실 과열 경고 등).
- 튜토리얼 스킵/다시 보기, 색 외의 형태로 적 위험 구분, 글자 크기·명암 개선.
- 일일 도전·업적·최고 기록 등 재방문 동기. 실제 재미를 검증한 뒤 선택.
- 로컬 세이브 내보내기/불러오기(재설치·기기 이동 수요가 확인되면 도입).

### P2 — 정식 오픈 이후 검토

- 신규 캐릭터, 신규 층/보스, 시즌 이벤트, 랭킹.
- 회원가입·클라우드 세이브·멀티플레이·결제. 현재 MVP에는 포함하지 않는다.
- 3D 오픈월드 또는 GTA와 유사한 자유 도시 플레이는 **별도 프로젝트 규모**로 분리한다.

## 7. 사용자 여정과 품질 기준

1. **링크 진입:** 5초 내 첫 화면 표시 목표(기준 네트워크·기기 측정), 시작 버튼이 명확해야 함.
2. **캐릭터 선택:** 능력 차이와 난이도 표시. 추천 입문 직장인을 제시.
3. **첫 30초:** 이동, 자동 공격, 스킬, 돌진 설명이 실제 입력과 연결.
4. **3분 전투:** 공격 경고, 현재 목표, 체력·경험치·스킬 쿨다운 읽기 쉬움.
5. **결과:** 성공/실패 이유, 보상과 새로 열린 요소, 재도전/다음 층 진입.
6. **재방문:** 진행 기록 복원, 이어서 할 목표 명시, 저장 방식 안내.

핵심 테스트는 **데스크톱 1920×1080 / 1366×768, 모바일 390×844 / 360×800 / 320×568** 등에서 실시한다. 실제 기기·브라우저 조합과 네트워크 조건을 테스트 기록에 남긴다.

## 8. 플레이테스트와 지표

**대상:** 처음 게임을 보는 사람 10~15명(PC·Android·iPhone 균형), 게임 경험이 적은 사람 포함.

**과제:** 설명 없이 시작 → 이동과 스킬 사용 → 첫 층 보스 도전 → 결과/재도전 → 브라우저 닫았다 다시 열기.

**권장 기록:** 시작 성공 여부, 첫 행동까지 걸린 시간, 조작 실패, 사망 이유, 첫 층 완료 여부, 각 단계 이탈, 재미 점수(5점 척도), 재플레이 의향, 오류/기기명. 개인정보가 불필요하면 익명·집계 중심으로 수집.

**Go/No-Go 예시:**
- 시작 성공률 100%, 첫 60초 이내 기본 조작 이해 80% 이상.
- 첫 층을 2회 이내 시도해 클리어한 참가자 70% 이상.
- 세이브 재방문 확인 100% (지원 저장 환경 기준).
- 치명적 버그 0건, 해결되지 않은 진행 차단 버그 0건.
- 모바일 평균 30FPS 목표 충족(선정된 기준 기기·동일 전투 조건).
- 참여자 70% 이상이 “다시 플레이하고 싶다” 응답.

값은 초기 **목표안**이며 베타 조사 후 현실적으로 조정한다.
